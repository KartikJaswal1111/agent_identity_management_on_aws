# Certification

![Design Authentication, Authorization, and Logging - Proficient badge](docs/images/certificate.png)

Completed the **"Design Authentication, Authorization, and Logging"** hands-on lab via the BeSA
workshop platform - proficiency badge above. The lab itself is AWS's own **SEC307: Agent Identity
Management** re:Invent workshop content, delivered through BeSA's Workshop Studio-based
environment rather than directly through AWS: every script in [`code/`](code/) is labeled
"SEC307 Workshop" in its own comments, and [`code/agent_core.py`](code/agent_core.py) carries
AWS's own MIT-No-Attribution copyright header - both signs this is the genuine AWS lab, not a
BeSA-authored equivalent.

This repository is the independent write-up of that hands-on work - see the
[main README](README.md) for the full breakdown and the [disclaimer](README.md#disclaimer) on how
this relates to AWS and BeSA.
